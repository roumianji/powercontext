# 阶跃星辰参赛题资产

`mini-kb/` 为 seekdb × 阶跃星辰端侧推理优化与混合检索项目。启动、固定模型下载、三配置测评、实测数据和已知限制详见 [README](mini-kb/README.md) 与 [技术说明](mini-kb/TECHNICAL_NOTE.md)。

在 `mini-kb` 运行 `pnpm install --frozen-lockfile`、`npm run models`、`npm run dev`。模型下载固定 revision 并校验全部 SHA256；开发、构建、启动命令也会自动检查。原始日志、报告与界面截图在 `mini-kb/evidence/`。
